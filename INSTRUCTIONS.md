# Trace
- Start recording with spt_trace_start (⚠️ this will override the current trace ⚠️)
- Stop recording with spt_trace_stop
- View the trace with spt_draw_trace & spt_hud_trace
- Scrub through the trace with "bind mwheeldown spt_trace_prev_tick; bind mwheelup spt_trace_next_tick", or use spt_trace_set_tick
- Save the trace to show your friend(s) with spt_trace_export
- Load the trace from your frien with spt_trace_import (⚠️ this will override the current trace ⚠️)
